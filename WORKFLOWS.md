# Brass Pawn: Chess Trainer — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## A short daily tactics session

Solve a small set without rushing. For each miss, name the tactical pattern and the defensive resource you overlooked. Repeat the missed position later without looking at the answer. Time spent understanding one error can be more useful than completing many guesses.

## Practice quiet positions

Treat a positional exercise differently from a forced-win puzzle. Compare piece activity, king safety and pawn structure before searching for a tactic. Use engine feedback to investigate candidate moves, not to memorize an evaluation number.

## Study an endgame

State the goal and the defender's best response before moving. Play both sides when possible and examine where the result changes. Do not extrapolate a verified position into a rule that applies to every superficially similar ending.
